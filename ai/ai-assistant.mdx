The AI Assistant helps you turn a monitoring goal into a plan and create the checks you approve. Generated Browser and Multistep Checks include a check intent: the goal and required outcomes that [automatic repair](../resolve/automatic-check-repair) must preserve.

<Accordion title="Prerequisites">

- A Trial, Starter, Team, or Enterprise account with Rocky AI enabled
- Permission to create checks in the account
- Any test credentials your journey needs, stored as [Checkly variables or secrets](../platform/variables)

</Accordion>

## Create a check

1. Open **AI Assistant** in the Checkly app and select **New**.
2. Describe the site, app, or API you want to monitor. Include the starting point, the journey, and the observable outcome that should pass.
3. Review the proposed monitoring plan. Ask the assistant to adjust the flow, assertions, frequency, locations, or alerting before you approve it.
4. Select the checks you want and choose **Create checks**.
5. Open each new check, run it, and review its script, assertions, and **Check intent** under **Automatic Repair**.

For a browser journey, ask for a Browser Check. For an API workflow with several requests, ask for a Multistep Check. If a journey has important negative cases or guardrails, describe them in your request and confirm they appear in the generated intent.

The generated intent does not turn on automatic repair by itself. [Set automatic repair for each check](../resolve/automatic-check-repair#enable-automatic-repair) after you have reviewed the check.

To replace a deprecated Agentic Check, follow the [Agentic Check migration guide](../detect/synthetic-monitoring/agentic-checks/migrate).
