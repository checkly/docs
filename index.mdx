# Build with Checkly

Testing, monitoring, and incident communication in one AI-native platform.

## Onboard your agent

Run this in your project directory. It installs the Checkly CLI and [Checkly Skills](/ai/skills), creates a `checkly.config.ts`, and copies a starter prompt for your coding agent:

```bash
npx checkly init
```

## Installation

**Checkly CLI**

```bash
npm install --save-dev checkly
```

**Checkly Skills** for Claude Code, Cursor, Codex, and other agents

```bash
npx checkly skills install
```

## Explore the platform

- [Detect](/detect/overview): synthetic monitoring, uptime monitoring, and testing
- [Communicate](/communicate/overview): alerts, status pages, and dashboards
- [Resolve](/resolve/overview): traces, Rocky AI root cause analysis, and debugging

    name: 'Homepage uptime',
    frequency: Frequency.EVERY_1M,
    request: {
      url: 'https://www.checklyhq.com',

  })
