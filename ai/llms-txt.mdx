Checkly publishes several resources based on the [llms.txt proposal](https://llmstxt.org/). Use the docs index to discover relevant pages, then fetch only the pages your AI tool needs.

| Resource | Use it for |
| --- | --- |
| [`/llms.txt`](https://www.checklyhq.com/llms.txt) | A curated, site-wide overview of Checkly products, differentiators, documentation, guides, and AI resources. It links to the documentation index but does not list every documentation page. |
| [`/docs/llms.txt`](https://www.checklyhq.com/docs/llms.txt) | The generated documentation index. It links to a section index for each part of the site navigation, such as Docs, API Reference, and Learn. Hidden and noindex pages are excluded unless they are configured as searchable. |
| [`/docs/llms-full.txt`](https://www.checklyhq.com/docs/llms-full.txt) | The content of all pages included in the generated documentation index as one plain-text response. This file is large, so use it only when your tool can process the full corpus. |
| [`/docs/_llms/docs.txt`](https://www.checklyhq.com/docs/_llms/docs.txt) | A section index. It lists every page in one navigation section with its title, description, and Markdown URL. Find the current section index URLs in `/docs/llms.txt`, because their names and contents follow the site navigation. |
| `/docs/<page>.md` | The Markdown representation of one documentation page. These responses include `X-Robots-Tag: noindex, follow` to avoid competing with the canonical HTML pages in search results. |

<Accordion title="Before you begin">

Use an HTTP client such as `curl`. These public documentation resources do not require authentication.

</Accordion>

Fetch the documentation index first, follow a section index, then retrieve individual pages from it:

```bash
# Fetch the generated documentation index
curl --fail https://www.checklyhq.com/docs/llms.txt

# Fetch the index for the Docs section
curl --fail https://www.checklyhq.com/docs/_llms/docs.txt

# Fetch one page as Markdown
curl --fail https://www.checklyhq.com/docs/detect/synthetic-monitoring/browser-checks/overview.md
```

Use [`/docs/llms-full.txt`](https://www.checklyhq.com/docs/llms-full.txt) only when you need the complete discoverable documentation set. For most tasks, fetching individual `.md` pages from a section index uses less context and is easier to keep relevant.
