## Public API

<Note>
The Error Groups endpoints under `/v2/error-groups` are in beta and are not in the [API reference](/api-reference) yet. They can change before they leave beta.
</Note>

The endpoints use the same base URL and authentication as the rest of the [Checkly API](/api-reference): `https://api.checklyhq.com`, an API key in the `Authorization: Bearer` header and your account ID in the `X-Checkly-Account` header.

The `/v1/error-groups` endpoints in the API reference are about failed checks, not about Errors from your applications.

| Method | Path | What it does |
|---|---|---|
| `GET` | `/v2/error-groups` | List Error Groups. |
| `GET` | `/v2/error-groups/{errorGroupId}` | Get one Error Group. |
| `GET` | `/v2/error-groups/{errorGroupId}/errors` | List its newest Errors with stack traces and breadcrumbs. `limit` 1 to 50 (default 10) and `offset`. |
| `PUT` | `/v2/error-groups/{errorGroupId}/status` | Set the status: `{"status": "resolved"}`. `unresolved` reopens it, `ignored` ignores it. |
| `PUT` | `/v2/error-groups/{errorGroupId}/assignee` | Assign it: `{"assigneeId": "<user id>"}`, or `null` to unassign. |
| `POST` | `/v2/error-groups/{errorGroupId}/merge` | Merge up to 25 Error Groups into this one: `{"loserIds": ["<id>"]}`. |
| `POST` | `/v2/error-groups/{errorGroupId}/unmerge` | Undo the merge of an Error Group that was merged away. |
| `POST` | `/v2/error-groups/{errorGroupId}/split` | Move one grouping key into a new Error Group: `{"fingerprint": "<key>"}`. |

The list takes these query parameters. Repeat a parameter to match any of its values, for example `status=unresolved&status=ignored`.

| Parameter | Values |
|---|---|
| `project` | A project's logical ID |
| `status` | `unresolved`, `resolved`, `ignored` |
| `assigned` | `me`, `none` or a user ID |
| `environment`, `platform` | Error Groups that ever reported from this environment or SDK platform |
| `handled` | `false` for Error Groups with at least one crash |
| `search` | Text in the title |
| `from`, `to` | UNIX timestamps in seconds, at most 30 days apart. Default: the last 24 hours |
| `sort` | `lastSeen` (default), `errors` or `age` |
| `limit`, `page` | 1 to 100 per page, default 25 |

The list counts at most 1,000 matches; narrow the filters to see more. Each endpoint allows 30 requests per minute for each caller. Reading needs `error-groups:read`, every change needs `error-groups:update`, and changing an assignee also needs `members:read`.

{/* [UNVERIFIED] Run this request against production and paste a shortened response. */}

```bash Terminal
curl "https://api.checklyhq.com/v2/error-groups?status=unresolved&sort=errors" \
  -H "Authorization: Bearer <your-api-key>" \
  -H "X-Checkly-Account: <your-account-id>"
```

## MCP tools

The [Checkly MCP server](/ai/mcp-server) lets an AI agent find, read and triage Error Groups, and set up projects and DSNs.

| Tool | Type | What it does |
|---|---|---|
| `search-error-groups` | Read | Find Error Groups by status, assignee, environment, platform, project or title. |
| `get-error-group` | Read | Get one Error Group. |
| `list-error-group-errors` | Read | List the newest Errors of an Error Group. |
| `list-error-group-breadcrumbs` | Read | List the breadcrumbs of an Error. |
| `update-error-group` | Write | Change the status or assignee of one Error Group. |
| `update-error-groups` | Write | Change the status or assignee of up to 100 Error Groups. |
| `merge-error-groups` | Write | Merge Error Groups. |
| `unmerge-error-group` | Write | Undo a merge. |
| `split-error-group` | Write | Split a grouping key into a new Error Group. |
| `list-projects` | Read | List projects. |
| `create-project` | Write | Create a project for Errors. |
| `create-ingest-key` | Write | Create a DSN for a project. |
| `list-ingest-keys` | Read | List a project's DSNs, including revoked ones. |
| `revoke-ingest-key` | Write | Revoke a DSN. |

Example prompt:

```text title="Prompt" wrap
Find the unresolved Error Groups with the most Errors in production this week, show me the stack trace of the top one, and assign it to me.
```
