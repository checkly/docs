The [Checkly plugin](https://github.com/checkly/checkly-plugin) bundles the official Checkly skills for AI coding agents in a single installable package. It targets Claude Code, OpenAI Codex, Cursor, and any agent supporting the plugins standard.

## Getting started

<Accordion title="Prerequisites">
  - A supported AI coding tool: [Claude Code](https://code.claude.com/docs/), [OpenAI Codex](https://openai.com/codex/), [Cursor](https://www.cursor.com), or another agent supporting plugins
  - [Node.js](https://nodejs.org) if you install via `npx`
</Accordion>

### Installation

<Tabs>
  <Tab title="Claude Code">
    Add the Checkly plugin marketplace and install the plugin from within Claude Code:

    ```txt
    /plugin marketplace add checkly/checkly-plugin
    /plugin install checkly@checkly
    ```
  </Tab>
  <Tab title="OpenAI Codex">
    Add the Checkly plugin marketplace from your terminal:

    ```bash
    codex plugin marketplace add checkly/checkly-plugin
    ```

    Then open Codex and enable the Checkly plugin via `/plugins`.
  </Tab>
  <Tab title="Cursor">
    Point Cursor at the [checkly/checkly-plugin](https://github.com/checkly/checkly-plugin) repository to install the plugin.
  </Tab>
  <Tab title="Plugins CLI">
    For agents supporting the generic plugin format, install the plugin with the `plugins` CLI:

    ```bash
    npx plugins add checkly/checkly-plugin
    ```
  </Tab>
</Tabs>

After installation, restart your AI agent to load the plugin.

## What the plugin provides

The plugin ships two skills. Both are synced daily from their source repositories, so you always get the latest guidance.

| Skill | Description |
| --- | --- |
| `checkly` | Set up, create, test, and manage monitoring checks with the Checkly CLI. See [Checkly Skills](/ai/skills) for details on what the skill covers. |
| `playwright-best-practices-for-agents` | Agent-first best practices for writing, structuring, debugging, and stabilizing Playwright tests. |

## Usage

Once installed, your agent automatically loads the relevant skill whenever a Checkly or Playwright task comes up — no manual context loading required.

```txt Claude Code Example highlight={3-4}
❯ Can you create a new URLMonitor with Checkly for example.com?

⏺ Skill(checkly:checkly)
  ⎿ Successfully loaded skill · 3 tools allowed

⏺ Let me read more references and check the existing project structure
```

In agents supporting slash commands, you can also invoke the bundled skills explicitly:

```txt
/checkly:checkly
/checkly:playwright-best-practices-for-agents
```

<Note>
If you only want the Checkly monitoring skill without the plugin wrapper, install it directly via the Checkly CLI. See [Checkly Skills](/ai/skills).
</Note>
