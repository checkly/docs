# Checkly Documentation

Checkly is the Application Reliability Platform for engineering teams: Playwright-powered monitors defined in TypeScript, run from global locations, with traces for every failure.

## Onboard your agent

Run this in your project directory. It installs the Checkly CLI and [Checkly Skills](/ai/skills), creates a `checkly.config.ts`, and copies a starter prompt for your coding agent:

```bash
npx checkly init
```

## Installation

**Checkly CLI**

```bash
npm install --save-dev checkly
```

**Checkly Skills** for Claude Code, Cursor, Codex, and other agents

```bash
npx checkly skills install
```

## Explore the platform

- [Detect](/detect/overview): synthetic monitoring, uptime monitoring, and testing
- [Communicate](/communicate/overview): alerts, status pages, and dashboards

<Tabs>
  <Tab title="Browser Check" icon="window">
  ```ts __checks__/homepage.spec.ts
  import { test, expect } from '@playwright/test'

  test('homepage loads', async ({ page }) => {
    const response = await page.goto('https://www.checklyhq.com')
    expect(response?.status()).toBeLessThan(400)
    await expect(page).toHaveTitle(/Checkly/)
  })
  ```
  </Tab>
  <Tab title="API Check" icon="code">
  ```ts __checks__/runtimes-api.check.ts
  import { ApiCheck, AssertionBuilder } from 'checkly/constructs'

  new ApiCheck('runtimes-api', {
    name: 'Runtimes API',
    request: {
      method: 'GET',
      url: 'https://api.checklyhq.com/v1/runtimes',
      assertions: [AssertionBuilder.statusCode().equals(200)],
    },
  })
  ```
  </Tab>
  <Tab title="URL Monitor" icon="globe">
  ```ts __checks__/homepage.check.ts
  import { Frequency, UrlAssertionBuilder, UrlMonitor } from 'checkly/constructs'

  new UrlMonitor('homepage-uptime', {
    name: 'Homepage uptime',
    frequency: Frequency.EVERY_1M,
    request: {
      url: 'https://www.checklyhq.com',
      assertions: [UrlAssertionBuilder.statusCode().equals(200)],
    },
  })
  ```
  </Tab>

    grace: 2,
    graceUnit: 'hours',
  })
