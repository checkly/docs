The fastest way through this guide is to hand it to your coding agent. Install [Checkly Skills](/ai/skills) once, in your project or globally, so the agent knows the CLI, the constructs, and the confirmation rules for deploys:

```bash Terminal
npx checkly skills install
```

Then copy the prompt below into Claude Code, Cursor, Codex, or any agent that supports skills. It reads the same `npx checkly skills` context you would, writes the code, proves it with `npx checkly test --record`, and stops for your confirmation before `npx checkly deploy`.
