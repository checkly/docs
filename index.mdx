# Checkly Documentation

Checkly is the Application Reliability Platform for engineering teams: Playwright-powered monitors defined in TypeScript, run from global locations, with traces and AI root cause analysis for every failure.

## Set up Checkly in a project

Run this in your project directory. It installs the Checkly CLI and [Checkly Skills](/ai/skills), creates a `checkly.config.ts`, and copies a starter prompt for your coding agent:

```bash
npx checkly init
```

To install only the skills for Claude Code, Cursor, Codex, and other agents:

```bash
npx checkly skills install
```

## Explore the platform

```txt
Set up Checkly monitoring in this project.

1. Install the Checkly skills for this agent with `npx checkly skills install`, then load the Checkly skill before writing any code. If `checkly` is not a dev dependency yet, add it with `npm install --save-dev checkly`.
2. If there is no `checkly.config.ts`, create one with `defineConfig` from 'checkly'. Reference: https://www.checklyhq.com/docs/cli/overview.md
3. Inspect the project structure, existing tests, and endpoints. Create a small set of monitors as code that match this codebase: URL monitors for key pages, API checks for important endpoints, and Browser Checks or a Playwright Check Suite if a Playwright config exists. Start with the most critical flow, not full coverage.
4. Ask me for an alert email address or Slack channel and create at least one alert channel assigned to the checks. Do not use placeholder values.
5. Run `npx checkly test --record` and fix anything that fails. If I am not logged in, ask me to run `npx checkly login`.
6. Show me what you changed and stop for my confirmation before running `npx checkly deploy`.

Documentation index: https://www.checklyhq.com/docs/llms.txt (append .md to any docs URL for Markdown).
```
