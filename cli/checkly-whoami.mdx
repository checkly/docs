The `checkly whoami` command displays detailed information about your current Checkly authentication, including the logged-in user account and active Checkly account details.

If you aren't logged in, the command starts `checkly login` in an interactive terminal. In CI, it fails with an error instead.

## Usage

The basic command shows current authentication status and account information.

```bash Terminal
npx checkly whoami
```

Use `--output json` (or `-o json`) to get the user and account details as JSON.

### Authenticated

If you're logged in, you'll see:

```bash Terminal
npx checkly whoami

You are currently on account "Monitoring as Code" (b2f...) as Raccoon.
Plan: Team
```

### Not Authenticated

If you aren't logged in and the command can't start the login flow, for example in CI, you'll see:

```bash Terminal
npx checkly whoami

Error: Run `npx checkly login` or set `CHECKLY_API_KEY` & `CHECKLY_ACCOUNT_ID` in your environment or .env file.
```
